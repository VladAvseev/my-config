# my-config

Личная коллекция конфигураций: одна папка — одно приложение, рабочие файлы
с оригинальными именами и README с инструкцией по установке и применению.

| Папка | Приложение |
| --- | --- |
| [`terminal/`](terminal/) | foot + zsh |
| [`opencode/`](opencode/) | OpenCode CLI |
| [`vscode/`](vscode/) | Visual Studio Code |
| [`_template/`](_template/) | скелет для нового приложения |

Конвенции и правила для агентов — в [AGENTS.md](AGENTS.md).
Секретов в репозитории нет: ключи подставляются из переменных окружения.
